Desafio de Ransomware - Cybersecurity DIO

Funcionamento básico de criptografia e descriptografia de arquivo, usando a biblioteca "pyaes" em Python.

* Encapsulamento: Uso de funções `def` para organizar a lógica.
* Segurança: Implementação de `with` para manipulação segura de arquivos (fechamento automático).
* Tratamento de Erros: Uso de `try/except` para evitar que o programa trave em caso de falhas ou arquivos ausentes.
* Verificação de Caminho: Checagem de existência do arquivo antes de iniciar o processo.
